Threat model: a personal home-LAN tool with first-party addons. This check covers normal map navigation, theme changes and photo selection.

## Running application

Used the actual map module and bundled MapLibre in Chromium with software WebGL, through the existing map fixture on loopback port 4283. This was a separate browser walkthrough after the permanent acceptance suite. The map opened at Ueno/Shinobazu Pond, center `[139.7715, 35.7131]`, zoom 14, with public OpenStreetMap Shortbread tiles and one synthetic placeholder photograph. A routed test-only library wrapper exposed the instance for observing bearing, center and zoom; no production API was added.

Sent actual browser mouse and keyboard inputs and CDP two-contact touch input, capturing each resulting view:

- Right-button drag, Ctrl+left-button drag, Shift+left/right arrows and a two-finger twist all retained bearing 0 and the original zoom and center.
- Ordinary mouse dragging changed center longitude from 139.7715 to 139.76375. ArrowRight moved it to 139.76804.
- Keyboard `+` changed zoom 14 to 15; wheel zoom reached 15.54806. The zoom-in and zoom-out buttons changed zoom by +1 and -1. A two-finger pinch increased zoom to 16.94970. Bearing stayed 0 throughout.
- Switched to dark theme and attempted keyboard rotation. Hid and paused the map, changed to light theme, showed and resumed it, then attempted right-button rotation. Destroyed and recreated the map and attempted another two-finger twist. Each view retained bearing 0.
- Pressed the recreated map's photo pin. Its callback returned exactly `placeholder-photo`.

Inspected the full-size opening, dark-theme and final photo-click screenshots. Tiles, labels, controls and the placeholder pin rendered; the dark palette applied and the recreated light view restored. No page errors occurred. Requests reached only loopback and `vector.openstreetmap.org`.

Result: PASS. No functional item remains pending for this change. Physical touch hardware and household LAN performance were outside this local-browser check.
