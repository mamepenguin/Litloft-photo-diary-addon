# Photo Diary: 写真を眺めるための地図

SPEC-ID: SPEC-PD-013

Approval: sha256:e06b903d879e65532928d8ace7da52a76f97ed8ffcc85a0253653f41e312874a Yuichi Senga 2026-11-02

## Summary

地理的な特徴を残した淡い背景地図にする。既存のMapLibreとShortbreadタイルを使い、水域・緑地・鉄道を手掛かりとして写真を主役にする。ユーザーが2026-11-02に承認した方向を具体化した仕様。

## Required items

### 1. Normal flow

地図を開き、写真ピンを眺め、拡大すると周辺環境の情報が増える。以下のズームは描画側の下限。配信タイルにない地物は補完しない。

| 要素 | 条件 |

| 陸地・海・湖 | 既存の形状を単色で描く |
| 河川 | 河川ポリゴンと河川線を海と別色にする。線幅1.2px |
| 森林 | forest / wood |

| 建物 | z14以上、輪郭・高さ表現なし |
| 高速・幹線道路 | 既存の種類と幅を維持 |
| 一般道路 | 既存の種類と幅、z13以上を維持 |
| 細街路・歩道 | service / pedestrian / footway / path、z16以上、0.5pxからz19で1px、輪郭なし |
| 鉄道 | 既存のrail、1pxの実線、単色 |
| 国・都道府県名 | boundary_labelsのadmin_level 2 / 4、z2 / z5以上、14 / 13px |
| 都市名 | 既存のcapital / state_capital / city / town / village、既存の文字サイズ |
| 町名等 | suburb / quarter / neighbourhood、z14以上、12px、補助文字色 |
| 駅名 | public_transportのstation、z13以上、12px、主要文字色 |

| 施設名 | poisの観光名所・動物園・水族館・博物館、z13以上、12px、施設文字色 |

### 2. Failure cases

タイル失敗通知・再読込・サムネイル失敗時の表示を維持する。欠落した地物・名前・カテゴリは表示されない。タイル失敗後もピンを押せる。ラベル追加によるエラー画面は設けない。

### 3. States

ライト／ダーク、表示中／非表示、読み込み中／成功／タイル失敗は既存と同じ。テーマ変更は表示中なら即時に再配色し、非表示中なら復帰時に適用する。ズーム条件はMapLibreに任せ、新しいアプリ状態を持たない。

### 4. Data read and written

既存の写真位置・サムネイル・タイル・同梱文字を読む。DB・写真・設定・ブラウザ保存形式への変更なし。

### 5. External services

設定済みタイルサーバーだけを使用する。地形・施設検索・フォントサービスは追加しない。遅延・停止時の扱いは既存と同じ。収録属性は https://shortbread-tiles.org/schema/1.0/ と実配信タイルで確認する。

### 6. Authorization

既存のドライブ認可・アドオンポリシー・サムネイル認可を維持する。API追加なし。

### 7. Effect on existing features

アドオンのdocs/specs/ui-polish.md、SPEC-PD-010の配色・レイヤー表と「建物・施設等は表示しない」という制限を置き換える。同仕様I7（外部通信）・I8（テーマ切替）は維持する。写真ピン・クラスタ・選択・写真一覧・カレンダーは変更しない。

### 8. Error behavior

文言・ログは既存のまま。未収録の名前は欠落として扱い、地図全体を失敗扱いにしない。

### 9. User-visible behavior

水域・公園・森林の違いが淡い色で分かり、鉄道が灰色の実線になる。広域では写真の分布、拡大時には建物・駅などの周辺環境を読める。写真ピンは背景・ラベルより手前に出る。

### 10. Non-functional

タイルURL・同梱文字・z14タイルからz19までの拡大を維持する。追加依存・契約・APIキーなし。写真密度計算は追加しない。私的な写真を共有アーティファクトに載せない。

## Invariants

I1. 道路名・路線名・住所・番地・一般店舗・ホテル・商業施設・病院・学校・銀行のラベルは全ズームで描かれない。

I2. z14未満では建物、z16未満では追加する細街路・歩道が描かれない。

I3. 鉄道は両テーマで単色の細い実線であり、河川と海、公園と森林にそれぞれ指定色が使われる。

I4. テーマ切替では全地図色が変わり、地図位置・ズーム・選択中の一覧・読み込み済みタイルは保持される。非表示中の変更も復帰時に反映される。

I5. 外部ホストの追加や写真・DBへの書き込みは発生せず、既存認可とリファラ制約を維持する。

I6. ピンの写真・件数・クラスタ構成・クリック結果・タイル失敗後の操作はスタイル変更で変わらない。

I7. 名前のない地物と許可カテゴリ以外の施設にはラベルを出さず、ラベル同士の重ね描きを強制しない。

## Verification

別エージェントが仕様だけから受け入れテストを設計する。変更する契約の既存テストを更新し、焦点を絞ったテストをREDからGREENにする。関連vitest・型検査・lint・precheckを実行する。実配信タイルで都市・水辺・公園のz9/13/14/16、両テーマ、テーマ切替、写真との重なりを実ブラウザ確認する。実装者以外がR-5を行い、画像と残件を記録する。

## Checked, no action

- ライブラリ・タイル提供元・写真ピン・ページレイアウトは変更しない。
- 以前の承認済み仕様自体は編集しない。
